# Simple Linux server Performance Stats

A Bash scripting project that monitors basic Linux server performance stats.

## Project Overview

This project aims to provide a quick overview of Linux server performance through a simple Bash script.

## Features

- [ ] Total CPU usage
- [ ] Total Memory usage (used and free, in a percentage format)
- [ ] Total disk usage (used and free, in a percentage format)
- [ ] Top 5 processes by CPU usage
- [ ] Top 5 processes by Memory usage

## Technologies Used

- Debian Linux version 13 
- Bash Scripting
- Git
- GitHub

## Requirements

- Linux operating system
- Bash
- procps
- sysstat
